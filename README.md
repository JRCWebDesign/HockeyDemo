# Pinar Hockey

Demo responsive del sitio de Pinar Hockey, en HTML, CSS y JavaScript sin dependencias.

## Vista local

Desde esta carpeta, ejecutar `python -m http.server 5173` y abrir http://localhost:5173.
También se puede abrir `index.html` directamente.

## Contenido

- Portada con fotografía y efecto de profundidad.
- Animación de entrada de 2,7 segundos.
- Categorías y enlaces de contacto.
- Galería de prueba con navegación y soporte de teclado.
- Fondo ilustrado con palos de hockey.

Las imágenes de jugadoras y las ilustraciones son generadas para la demo. Los espacios de la galería deben reemplazarse por fotos del club.
